# 🚗 MoveCar Pro - 多用户智能挪车系统 (Docker 私有化部署版)

一个基于 Node.js + Redis 构建的现代化、高颜值、重隐私的智能挪车通知系统。专为 NAS (如飞牛 fnOS、群晖、绿联) 和个人云服务器设计，支持一键 Docker Compose 部署。

经历了彻底的底层重构，MoveCar 现已进化为 **SaaS 级多用户平台**，告别繁琐的配置文件，全面拥抱 Web 可视化管理！

---

## ✨ 颠覆性的核心特性

* **💻 现代化 SPA 管理控制台**：内置精美的单页应用（SPA）后台，支持无刷新 Tab 切换、高对比度表单，所有配置即改即生效，无需重启容器！
* **🚀 推送通道大满贯 (9 大通道)**：完美支持 WxPusher(首选)、PushPlus、Server酱、Bark、Telegram 机器人、企业微信(高颜值图文卡片)、钉钉机器人、自定义 Webhook，以及 **通用 SMTP 邮件推送**。
* **🎨 纯前端高定海报引擎**：内置 15 款精美挪车海报（法式轻奢、赛博朋克、红丝绒、JDM 等）。采用 `html2canvas` 纯前端超采样渲染，不消耗 NAS 服务器算力，一键保存 300dpi 打印级高清图！
* **⚡ JSON 模板热更新**：支持在后台直接修改或新增海报模板 JSON，瞬间生效，零宕机。
* **🛡️ 智能防骚扰博弈机制**：扫码者若拒绝授权地理位置，系统将触发“30秒强制罚站倒计时”后才能发送通知，极大程度过滤恶意扫码骚扰。
* **🗺️ 智能导航与状态同步**：多端扫码状态实时同步（已处理/已失效）。支持扫码者位置精准纠偏 (GCJ-02)，为车主提供一键高德/苹果地图精确导航。

## 📦 保姆级快速部署指南

本系统采用极简的 Docker Compose 架构，以下是保姆级 SSH 部署教程。

### 1. 选择目录并克隆代码 (⚠️ 重要)
通过 SSH 登录你的 NAS 或服务器后，请先进入你平时专门存放 Docker 项目的承载目录（例如飞牛 NAS 的 `/vol1/1000/Docker` 或群晖的 `/volume1/docker`），然后再执行下载命令： (直接下载项目文件，然后手动上传也行，看个人习惯)

```bash
# 1. 进入你的 Docker 数据存放目录（请根据你的实际路径修改）
cd /你的/Docker/专属/目录

# 2. 克隆本项目代码
git clone https://github.com/nbbk/MoveCar-Docker-NB.git

# 3. 进入刚刚下载好的项目根目录
cd MoveCar-Docker
```

### 2. 配置管理密码
使用文本编辑器（或 `nano docker-compose.yml`）打开配置文件，修改唯一的必填参数（具体方式根据自己喜欢的来）：
* 将 `ADMIN_PASSWORD=123456` 改为你自己的控制台登录密码。
* *(如需使用海外 Bark 或 Telegram 节点，请解除 `HTTP_PROXY` 的注释并配置局域网代理)*

### 3. 一键构建并启动
在项目根目录下执行：
```bash
docker compose up -d --build
```
等待镜像构建完成后，服务将运行在宿主机的 `13000` 端口。使用你习惯的反向代理（Nginx/Lucky/宝塔等）**将 `13000` 端口映射并绑定 HTTPS 域名**即可正式使用！

## ⚙️ 系统初始化与基础配置

系统首次启动后，是一个完全隔离的“空壳”，你必须完成以下步骤：

1. **登录后台**：访问 `https://你的域名/admin`，输入你在 `docker-compose.yml` 中设置的密码。
2. **配置主域名 (核心)**：进入 **【系统全局设置】**，填写 **外网访问主域名**（必须以 `https://` 开头，末尾不带/斜杠）。*只有配置了主域名，系统才能生成二维码和获取 GPS 定位！*
3. **添加第一辆车**：切换到 **【车主与通道管理】**，点击新增。填写唯一标识（如 `mycar`），并绑定你想使用的推送通道凭证（如 WxPusher UID、邮箱地址等），保存即可。

## 📧 SMTP 邮件发件终极配置指南 (必看避坑)

邮件推送是到达率最高、最通用的兜底通知方案。在 **【系统全局设置】** -> **【邮件发件服务器 (SMTP)】** 中，请严格按照以下规范填写：

### 参数对照表与详解

| 配置项 | 应该填什么？ | ⚠️ 避坑与注意事项 |
| :--- | :--- | :--- |
| **SMTP 服务器地址** | 服务商提供的发送地址。如：`smtp.qq.com` | 如果用 Resend，固定填 `smtp.resend.com`，绝对不要填你自己的域名。 |
| **端口** | 推荐填 `587` 或 `465`。 | `465` 走强 SSL 协议，`587` 走灵活的 STARTTLS 协议。国内云服务器通常拦截 25 端口，**如果 465 发不出，请果断换成 587 测试**。 |
| **发件账号 (User)** | 你的登录邮箱。如：`12345@qq.com` | 如果用 Resend，固定填小写单词：`resend`。 |
| **授权码 (Password)** | 第三方客户端专用发信密码。 | **绝对不能填你平时的网页登录密码！** QQ邮箱是16位纯字母（无空格）；Gmail 必须在后台生成“应用专用密码”；Resend 则是你的 API Key。 |
| **自定义发件人名称** | `名称 <发件邮箱>`<br>例如：`挪车小助手 <12345@qq.com>` | **致命深坑！** 必须严格遵循 `文字 <邮箱>` 的格式，并且尖括号里的邮箱**必须与发件账号一致**，否则会被腾讯/谷歌等各大服务商直接拦截报 `501` 错误！ |

### 💡 QQ 邮箱实战举例
1. 电脑登录 QQ 邮箱网页版 -> 设置 -> 账号 -> 开启 `POP3/SMTP服务` -> 点击“生成授权码”。
2. 在 MoveCar 后台填写：
   * 地址：`smtp.qq.com`
   * 端口：`587`
   * 账号：`你的QQ@qq.com`
   * 密码：`获取到的16位英文字母`
   * 自定义发件人：`智能挪车系统 <你的QQ@qq.com>`

*注意：配置好全局发送服务器后，请务必去【车主管理】中，给具体的车主填上“通知接收邮箱”，否则系统不知道该发给谁哦！*

## ❓ 常见问题排查 (FAQ)

**Q：为什么我扫码时一直显示“无法获取位置”或提示防骚扰？**
* 现代浏览器的隐私策略严格规定，**只有在 HTTPS 协议下，浏览器才会允许网页调用 GPS 传感器**。请确保你的反向代理配置了有效的 SSL 证书，并且通过 `https://` 访问。

**Q：为什么 PushPlus 能收到，Bark / TG 机器人 收不到？**
* 100% 是网络被阻断了。请在 `docker-compose.yml` 中配置 `HTTP_PROXY` 和 `HTTPS_PROXY` 局域网旁路由代理，然后执行 `docker compose restart` 重启服务。

**Q：终端报错 `no configuration file provided: not found` 怎么办？**
* 说明你当前终端所在的目录不对。请先用 `cd` 命令进入包含 `docker-compose.yml` 的 `MoveCar-Docker` 文件夹，再执行命令。
